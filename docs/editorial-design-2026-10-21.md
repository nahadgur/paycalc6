# Approved PAYE Calculator editorial identity

The owner approved the cream/coral Nairobi paper collage concept and the PAYE Calculator folded-payslip logo. This release implements the design in the existing site.

- Replaced the PAYE.CALC header/footer shorthand with a scalable folded-payslip mark and PAYE Calculator wordmark.
- Added the matching browser and Apple touch icons and organization logo metadata.
- Added a locally hosted Anton display font, with its SIL Open Font License.
- Created a bespoke Nairobi/payslip hero illustration with no illustrative financial amounts; delivered as a 195 KB WebP. Generated with the built-in image tool from the approved concept, then resized/encoded for delivery.
- Replaced the homepage poster with oversized editable HTML type and the illustration. The salary input, result and guide links remain real accessible page elements.
- Added a labelled numeric salary input and preset buttons; the result uses the existing tested fullCalculation function and updates immediately. Advanced reliefs, deductions, charts and other calculators remain available.
- Added three prominent guide links with graphic cutouts; retained existing hub/spoke links and metadata.
- Reduced the promotional bar height to keep the calculator easier to reach.
- Kept the illustration decorative and gave the result a polite live region; preserved keyboard focus styles and included reduced-motion support.

Validation: production build, existing payroll and article audit scripts, generated homepage checks for the logo, artwork, numeric input, expected default result, single H1 and absence of the old brand shorthand. Responsive CSS and headline font widths were checked. Browser visual testing was attempted but Chromium installation failed in this environment; no browser screenshot pass is claimed.

Artwork prompt: standalone paper payslip sculpture with PAYE/SHIF/NSSF/Housing Levy ribbons, coral geometry, cream background and halftone Nairobi skyline, matching the approved editorial concept. No numeric financial data or legacy PAYE.CALC wordmark.
